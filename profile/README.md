## Welcome to Terramate! 👋 👋🏿 👋🏻 👋🏽

We are a team of technologists and practitioners who believe the cloud enables innovation. Infrastructure as Code (IaC) stands in the center of the once-in-a-generation shift to the cloud, and we are helping organizations of all sizes, from well-known brands to ambitious scale-ups, to scale and simplify IaC so they can focus on innovating!

### 💻 Terramate CLI

[Terramate CLI](https://github.com/terramate-io/terramate) is an open source tool that supercharges Terraform environments with Stacks, Orchestration, Git Integration, Code Generation, Data Sharing and more. It focuses on improving the Developer Experience (DX), providing workflows and lowering the time spent writing and maintaining infrastructure code for projects at any scale.

### ☁️ Terramate Cloud

Terramate Cloud is a visibility and collaboration platform for teams using Terramate CLI. It integrates with your VCS (GitHub, GitLab) to enrich your pull request with the changed resources and stacks, it gives you an easy-to-decipher rendering of Terraform plans, and it detects failed deployments, partially applied plans, and drifts. It has an inbuilt alerting system that uses an implicit ownership graph (from the PRs) to allocate "homework" to the right platform team  member, and notifies via Slack or Teams. For team leaders, it offers 
out-of-the-box DORA metrics.
Terramate Cloud offers a generous free tier. [Sign-up now!](https://cloud.terramate.io/)
